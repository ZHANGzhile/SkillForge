# 固定程序的边界来源对照：预声明 v1

本实验检验失败证据是否改变边界及执行过程，不替换已发布模型、旧Skill或部署。先审计旧编译器，再单列新增的有限条件归纳算法；不得把新算法成绩归给旧实现。

## 固定项与分组

三族程序直接取冻结bundle：procedure、inputs、postconditions与Skill ID逐字节语义hash一致。四组仅边界条件不同；同一Gate、hydrate、工具层policy/权限/幂等、模型身份、16步总预算和1次重试。实验契约保持VALIDATING，仅由独立评测器装载，不进入正式Registry或线上验证技能。

A从成功train执行的声明特征中保留常量条件；B保留A并在同一有限特征域内增加条件，每步优先排除最多剩余失败、必须保留全部正例，平局先选eq再按条件内容hash排序，最多增加6条。C使用完整人工规则；D在C上执行同一反例精化，不放宽规则。算法是受限的单调精化，不能修复A的偶然过窄常量条件；该局限需显式报告。A不使用负例验证结果选边界。四组都评测，即使某组验证差，也不将其从报告剔除。

特征域按family声明，字段语义与refund.amount_valid等派生谓词是人工先验；学习器仅选择条件，不能声称发现支付算术。所有组共享这些先验。模型可见契约去掉实验分组、来源和统计，仅保留相同格式的执行必要字段与边界。模型仍看到既有公开policy，不人为削弱C或模型的规则知识。

## 数据与标签

独立目录boundary-study-v1，seed=20260930。train/validation/test使用不同ID、请求模板；train与validation含单条件，test含预声明保留组合。全部组合规格先于实验输出冻结并hash绑定。已知规则上的设计不是盲于业务语义；新ID不等于独立新场景。

训练证据由明确标识的实验控制器实际执行固定程序得到，保存输入、完整初态、工具前后状态、程序结果；成功执行是正例，业务拒绝是负例。超时/权限故障或程序内部绑定失败不当业务条件反例，单列excluded及错误原因，仍保留于完整评测。预检发现零金额退款在写入前因expected_total缺失而终止，因此不把它伪标为工具拒绝。本轮无新增真实模型采集或训练，不冒称自主模型经验。来源审计另外使用旧bundle中的真实轨迹。

纯Gate先测完整观察和固定缺失掩码：full、empty、hide_customer、hide_payment_or_shipment。分别保存完整业务适用性及在有限域内部分观察应有的三态标签。充分禁止事实存在时，即使其他字段缺失仍可判不适用。独立声明oracle用实际环境程序执行交叉检查；C可能与oracle等价，这是完整规则基线的预期性质。

## 主指标和支持标准

完整观察主指标为错误放行率：真实不适用分母中的APPLICABLE。错误拦截率为真实适用分母中的INAPPLICABLE；UNKNOWN、正常放行覆盖率单列。部分观察再报告三态混淆矩阵、补查前后UNKNOWN及查询/失败/重试成本。不能把UNKNOWN当正确拒绝。

主比较B-A、D-C。先按独立family×场景族计算指标，再场景族等权配对；同一实例的观察掩码不是独立样本。固定seed做2000次场景族配对bootstrap的95%百分位区间，仅表示此合成场景样本的不确定性，不代表真实流量总体。

支持边界收益需错误放行差值区间上界<0，错误拦截增加区间上界<=5个百分点；声称系统正常收益保留还要求正常任务成功差值区间下界>=-5个百分点。区间宽则证据不足，不以点估计自动宣称成功。报告全部配对改善/退步，零分母为null。模型/基础设施失败分别保留。

## 系统与候选使用点反事实

同一test任务运行四组自主系统评测。候选点由预先固定的test场景提供，每个任务起始处对应本族Skill，不依最终成败、Gate输出或模型选择筛选。所有点均做Gate与单次绕过对照，之后单列放行/阻止/UNKNOWN子集。

分叉发生在Gate补查之前：完整SQLite、故障队列、初始可见观察、请求及固定程序相同。边界分支有界补查并控制本次Skill尝试；绕过分支仅跳过该次Gate，保留程序内部读、assert、工具policy和幂等。此后两支继续相同组边界与同模型自由决策。不同组的绕过分支后续边界不同，不能合并计算为同一条分支。

Gate不替模型选择refuse/escalate：被挡后记录结构化失败，模型继续决定终态，EOC评价正确性。初始强制尝试不计模型调用，也不计模型自主违规意图；单列实验触发与自主后续拦截。工具成本从分叉前起计，含Gate补查。报告EOC、正常复用、无效写入、循环/耗尽、到正确终态步数、模型/token/工具成本及实际违规。

新规则适应不混入本轮，须另行冻结规则变化与特征空间。不得根据本轮test改算法或阈值；不以结果更换部署。

为避免重复GPU工作，若同一任务/模式下两个组的完整模型可见契约逐字段一致，则只执行一次，另一个组记录明确的等价引用；身份、轨迹和对照仍完整审核。该复用不算独立重复，也不估计服务运行随机性。边界仅逻辑等价而可见字节不同的组不复用。报告同时列逻辑分支数与实际执行数。
